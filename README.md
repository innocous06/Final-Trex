# Final-Trex

[![Language: JavaScript](https://img.shields.io/badge/language-JavaScript_ES6-18181f?style=flat-square)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![Framework: p5.js](https://img.shields.io/badge/framework-p5.js-18181f?style=flat-square)](https://p5js.org/)
[![License: MIT](https://img.shields.io/badge/license-MIT-18181f?style=flat-square)](LICENSE)

A browser-based endless runner game recreating the classic offline T-Rex arcade experience.

## Overview

Built using the p5.js canvas graphics library and p5.play sprite engine. It features continuous parallax ground scrolling, procedural obstacle generation, jump physics, collision detection, high score persistence via localStorage, and sound effects.

## Tech Stack

- **Language:** JavaScript (ES6)
- **Game & Physics Libraries:** p5.js, p5.play, p5.sound
- **Storage:** Web Storage API (localStorage)

## Usage

Open `index.html` in any modern web browser. No compilation or server setup required.
